Видео должно быть Unlisted на YouTube.
Сначала загрузите MP3 файл в GitHub репозиторий.
Затем введите точное имя файла здесь, например: lesson-02.mp3
Файл должен быть в корне репозитория рядом с members.html
Как загрузить аудио урок:
1
Запишите урок на телефон через Voice Memos. Экспортируйте как MP3.
2
Назовите файл по шаблону: lesson-02.mp3, lesson-03.mp3 и т.д.
3
Откройте GitHub → phoenix-course → кнопка «Add file» → «Upload files» → загрузите MP3.
4
Вернитесь сюда, введите имя файла выше и нажмите Сохранить.
5
Скачайте обновлённый members.html и загрузите на GitHub вместо старого.
